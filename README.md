# ZOMBIE KILLER

3D first-person zombie survival in the browser (Three.js): fight waves of 12 rigged zombie types, collect gems, sell them to Old Zeke and buy guns.

## Run locally
```
npm install
npm run dev      # bundle src/ -> game.js
npm start        # serve on http://localhost:5173
```
Press **F3** in-game for the FPS / draw-call overlay. Quality presets are in Settings.

## Ship
`npm run dist` builds a deployable `dist/` folder (drag it into Netlify Drop).

## Assets
CC0 assets from Quaternius and Poly Haven, tracked in `tools/assets.manifest.json`.
